# AGENTS.md

This project's AI/agent session guide lives in [`CLAUDE.md`](CLAUDE.md) — start
there. It is the bootstrap map: orientation, where each concern lives, the
non-negotiable rules (snake_case DB vs. camelCase wire, `owner_id` tenancy, the
three-place contract lockstep), the cascade engine, and gotchas.

Human-facing reference docs are in [`docs/`](docs/index.md). The vendored Atlas
framework documents itself under [`atlas/CLAUDE.md`](atlas/CLAUDE.md) and
per-package `atlas/packages/<pkg>/AGENTS.md`.
